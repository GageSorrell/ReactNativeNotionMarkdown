The package is organized around a pure document layer and React Native-facing layers.

## Renderer

Use the root export or `./renderer` when an application needs to display markdown content. `./renderer/ui` contains UI-level pieces that can be composed into a custom renderer.

## Editor

Use `./editor/ui` for `MarkdownEditor`, the ready-to-use editing surface, and `./editor` for the native editor primitives underneath it.
`MarkdownEditor` loads Markdown or a `MarkdownDocument` through `initial` and reports edits as a `MarkdownDocument` through `onChange`, so the same document can be passed to the renderer.
The native view itself exchanges a flat block list; `toEditorBlocks` and `fromEditorBlocks` in `./document` convert between that and the document model.
See [Editor](/docs/v1/guides/editor) for what the editor can represent.

## Provider

`./provider` exports `MarkdownProvider`, the theme, and the message catalog. Both `./editor/ui` and `./renderer/ui` re-export it, so you rarely need to import it directly. See [Customization](/docs/v1/guides/customization).

## Document and native layers

`./document` is the platform-independent engine. `./native` contains platform adapters. Keeping these boundaries explicit makes it easier to test transformations outside a device runtime.
